## Installation

I strongly recommend using [pip](https://pip.pypa.io/en/stable/) package manager to install requirements and Python3 interpreter to run the program.

```bash
pip3 install matplotlib
pip3 install termcolor
pip3 install functools
pip3 install heapq
pip3 install numpy
```

## Usage

Open a terminal in the _code_ folder found in the project root folder and simply run:

```python
python3 main.py [max_duration_of_simulation]
```

If no value is passed for `<max_duration_of_simulation>` it will be assumed to be 24 (hours).

Once the execution finishes the script will have saved all histograms in the _Pictures_ folder.
